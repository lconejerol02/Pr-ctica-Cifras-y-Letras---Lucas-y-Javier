# Cifras y Letras

## ¿En qué consiste el proyecto?

Este proyecto consiste en crear una versión del conocido juego **Cifras y Letras** utilizando el lenguaje de programación Java.

Está pensado para dos jugadores que comparten el mismo ordenador y juegan por turnos. El objetivo es conseguir puntos superando diferentes pruebas relacionadas con las matemáticas y las palabras.

## Pruebas disponibles

El juego cuenta con cuatro pruebas diferentes:

- **La cifra exacta:** aparece un número objetivo y los jugadores tienen que intentar alcanzarlo realizando cinco operaciones matemáticas con los números disponibles.
- **La palabra más larga:** se muestra un conjunto de letras y cada jugador debe intentar formar la palabra más larga posible. Después se comprueba si la palabra es válida.
- **La calculadora humana:** los jugadores tienen que resolver varias operaciones matemáticas en el menor tiempo posible. Se tiene en cuenta el tiempo y los aciertos.
- **Orden exprés:** es una prueba creada para este proyecto en la que hay que ordenar correctamente una serie de números.

## Modos de juego

El programa tiene dos modalidades:

- **Concurso completo:** se realizan todas las pruebas y se van acumulando puntos. Al terminar, se muestra el resultado de los jugadores y quién ha ganado.
- **Partida rápida:** permite escoger una prueba concreta para jugar directamente sin tener que realizar el concurso completo.

## Configuración

Desde el menú de configuración se pueden modificar algunos aspectos de las partidas:

- El número de repeticiones de las pruebas.
- La cantidad de letras que aparecen en la prueba de palabras.
- El número de operaciones de la prueba de calculadora humana.

## Cómo ejecutar el programa

Para ejecutar el juego es necesario tener Java instalado y disponer de un programa como Visual Studio Code.

Los pasos para iniciarlo son:

1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Abrir el archivo `CifrasYLetras.java`.
3. Ejecutar el programa desde el entorno o desde la terminal.

También se puede ejecutar escribiendo estos comandos en la terminal:

```bash
javac CifrasYLetras.java
java CifrasYLetras
```
